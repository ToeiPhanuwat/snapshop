# Flow ข้อมูล: Shopee Affiliate → เว็บเปรียบเทียบราคา

ฉบับปัจจุบัน (อัปเดต 2026-11-16) ใช้แทนบรีฟเดิม (2026-11-12) ส่วนที่เปลี่ยนไปจากบรีฟดูได้ที่ [บันทึกการตัดสินใจ](#บันทึกการตัดสินใจ)
ศัพท์: [GLOSSARY.md](GLOSSARY.md) · กฎนำเข้าในระบบ: [README.md](../README.md#กฎการนำเข้า-สรุป)

## ภาพรวม

```
F1  ลิงก์ affiliate (พอร์ทัล Shopee Affiliate)  ─┐
                                                 ├─ Merge (item_id) ─ แยกชนิดสินค้า ─ ไฟล์ CSV ─ inbox/ ─ พรีวิว ─ นำเข้า ─ API ─ เว็บ
F2  การ์ดสินค้าในหน้าค้นหา "Dr.PONG"            ─┘
```

| ขั้น | ทำอะไร | ใครทำ (ตอนนี้) | ผลลัพธ์ |
|---|---|---|---|
| F1 | กดปุ่ม "รับลิงก์แบบทีเดียวทั้งหมด" ในพอร์ทัล | ผู้ใช้ | ไฟล์ CSV (≤ 100 รายการต่อไฟล์) |
| F2 | อ่านการ์ดสินค้าจากหน้าค้นหา | ผู้ใช้ | item_id, ราคา, ประเภทร้าน, รูป |
| Merge | รวม F1 + F2 ด้วย item_id | Claude หรือผู้ใช้ | ไฟล์ merged |
| แยกชนิดสินค้า | ใส่ รหัสกลุ่ม / ชื่อกลุ่ม / วิธีจัดกลุ่ม | Claude | ไฟล์พร้อมนำเข้า |
| ส่งเข้าระบบ | วางไฟล์ใน `inbox/` | Claude หรือผู้ใช้ | ไฟล์รอนำเข้า |
| พรีวิว + นำเข้า | ดูผลก่อน แล้วกดนำเข้าหรือทิ้ง ที่ `/admin/inbox` | admin | ข้อมูลใน PostgreSQL |
| แสดงผล | API → Next.js | ระบบ | เว็บฝั่ง user / admin |

ข้อตกลง: Claude ไม่ใช้รหัสผ่านหรือคีย์ admin ของระบบ และไม่ทำ automation ที่พรางตัวเป็นคนบน Shopee

## F1 — ลิงก์ affiliate จากพอร์ทัล

- ปุ่ม "รับลิงก์แบบทีเดียวทั้งหมด" เลือกได้ครั้งละ ≤ 100 รายการ จึงได้หลายไฟล์ (ชุดตัวอย่าง 192 รายการ = 2 ไฟล์)
- คอลัมน์: `รหัสสินค้า, ชื่อสินค้า, ราคา, ขาย, ชื่อร้านค้า, อัตราค่าคอมมิชชัน, คอมมิชชัน, ลิงก์สินค้า, ลิงก์ข้อเสนอ`
- `ลิงก์สินค้า` = `https://shopee.co.th/product/{shopId}/{itemId}` (ระบบดึง shop_id จากตรงนี้ และตรวจว่า itemId ตรงกับรหัสสินค้า)
- `ลิงก์ข้อเสนอ` = ลิงก์ affiliate สั้น `s.shopee.co.th/...` สร้างใหม่ทุกครั้งที่กด จึงไม่นับเป็นการเปลี่ยนแปลงของสินค้า
- ไม่ใช้ Sub_id (ยังไม่จำเป็นเมื่อมีหมวดเดียว; ใช้แยกยอดคลิก/ออเดอร์ตามตำแหน่งปุ่มได้ในอนาคต)
- ข้อควรระวัง: ราคาบางแถวเป็นตัวย่อ ("1.0พัน"), ยอดขายส่วนใหญ่เป็นตัวย่อ ("200พัน+"), คอมมิชชันมี "฿", อัตรามี "%"

## F2 — การ์ดสินค้าในหน้าค้นหา

- ค้นหา "Dr.PONG" ได้ 10 หน้า (20 ต่อหน้า, 192 รายการ ณ 2026-11-10)
- เก็บ: `item_id`, ราคา, ประเภทร้าน, ลิงก์รูป (`.webp` บน susercontent.com)
- ประเภทร้านมาจากป้ายบนการ์ดใน HTML: class `ItemCardFlag--mall` → Mall, `ItemCardFlag--preferred` → ร้านแนะนำ, ไม่มีป้าย → ทั่วไป
- **วิธีทำตอนนี้: ผู้ใช้ดึงเอง**
  - กด Ctrl+S บันทึกหน้าพอร์ทัลแล้วไม่ได้ข้อมูล (หน้าสร้างด้วย JavaScript)
  - ไม่ทำ automation ที่สุ่มเวลาเพื่อไม่ให้เหมือนบอท
- ราคาจาก F2 ควรเป็นตัวเลขเต็ม แต่ไฟล์ merged ชุดแรกยังมีราคาย่อ 3 แถว (item 26261939392, 26505445953, 28484198010) → ระบบตั้ง REVIEW

## Merge F1 + F2

- คีย์ = `item_id` รายงานรหัสที่มีด้านเดียวก่อนส่งต่อ (มีใน F2 ไม่มีใน F1 = ไม่มีลิงก์ affiliate)
- ราคา: ใช้จาก F2
- ประเภทร้าน, รูป: จาก F2; ที่เหลือจาก F1
- **ต้องคงชื่อสินค้าเต็ม** อย่าตัดข้อความก่อน "Dr." ออก ระบบแยก `name_prefix` / `name_core` เอง ไฟล์ `drpong_merged_20261110_renamed.csv` ถูกตัดคำนำหน้าไป 95 แถว จึงใช้นำเข้าตรง ๆ ไม่ได้

## แยกชนิดสินค้า

กลุ่ม = รายการสินค้าชนิดเดียวกันที่ขายหลายร้าน ใช้เปรียบเทียบราคา กฎ 2 ชั้นตามลำดับ:
1. **ชื่ออังกฤษตรงกัน:** normalize ชื่อ (ตัวพิมพ์เล็ก, ตัดเครื่องหมาย/ช่องว่างซ้ำ, ตัดข้อความโปรโมชันภาษาไทย) ตรงกันถือเป็นชนิดเดียวกัน **ขนาดต่างกันถือเป็นชนิดเดียวกัน** (15 ml กับ 16 ml)
2. **กฎคำระบุสูตร:** ใช้คำ/รหัสสูตรในชื่อ (activeIN, U9.9, MC1, G89, P55, 28D, 711, BarrierX, Retinal-X, Bakuchiol, Astaxanthin ฯลฯ) รวมชื่อที่ต่างกันเล็กน้อย

คอลัมน์ที่เพิ่มในไฟล์:

| คอลัมน์ | ค่า |
|---|---|
| `รหัสกลุ่ม` | ป้ายในไฟล์: `E001…` (ชื่ออังกฤษตรงกัน), `R001…` (กฎคำระบุสูตร), `U001…` (ไม่มีคู่) — **ใช้แค่ภายในไฟล์นั้น** ระบบไม่เก็บ |
| `ชื่อกลุ่ม` | ชื่อของชนิดสินค้า |
| `วิธีจัดกลุ่ม` | `ชื่ออังกฤษตรงกัน` / `ตามกฎคำระบุสูตร` / `ไม่มีคู่` |

ข้อแนะนำสำหรับรอบถัดไป: ดูชื่อกลุ่มที่มีอยู่แล้วในระบบ (`/admin/types`) แล้วตั้งชื่อกลุ่มให้ตรงกัน ระบบจะจับคู่ชื่อที่ normalize แล้วกับกลุ่มเดิมได้ ไม่เกิดกลุ่มซ้ำ (ตัวอย่างที่เกิดแล้ว: "Dr.PONG 28D smart whitening drone acne activein serum Gen2" แยกเป็น 2 กลุ่ม)

## ไฟล์ที่ส่งเข้าระบบ

- CSV UTF-8 คอลัมน์ 14 ตัว: `รหัสสินค้า, ชื่อสินค้า, ราคา, ขาย, ชื่อร้านค้า, ประเภทร้านค้า, อัตราค่าคอมมิชชัน, คอมมิชชัน, ลิงก์สินค้า, ลิงก์ข้อเสนอ, ลิงก์รูปภาพ, รหัสกลุ่ม, ชื่อกลุ่ม, วิธีจัดกลุ่ม`
- `ประเภทร้านค้า` = `Mall` / `ร้านแนะนำ` / `ทั่วไป`
- วางไฟล์ใน `inbox/` ที่ root ของโปรเจกต์ (ชื่อไฟล์ลงท้าย `.csv` ห้ามมี `/ \ : * ? " < > |` หรือ `..`)
- แถวใดผิด ทั้งไฟล์ถูกปฏิเสธ หน้าพรีวิวแสดงปัญหาตามเลขแถว

## ในระบบ

1. admin เปิด `/admin/inbox` → ดูพรีวิว: รายการใหม่ / ราคาเปลี่ยน (เดิม → ใหม่) / จะถูกซ่อน / จะรอตรวจ / กลุ่มใหม่ — ยังไม่บันทึกอะไร
2. กด "นำเข้าไฟล์นี้" (ไฟล์ย้ายไป `inbox/imported/`) หรือ "ทิ้งไฟล์" (ย้ายไป `inbox/rejected/`)
3. ระบบสร้างรหัสกลุ่มของตัวเอง (`PT000001`) และใช้กฎกลุ่ม/ราคา/สถานะตาม [README](../README.md#กฎการนำเข้า-สรุป) — โค้ดหลักอยู่ที่ `backend/src/main/java/com/snapshop/service/importing/ImportPlanner.java`
4. เว็บ user แสดงเฉพาะกลุ่มที่มีร้านขายได้ ≥ 2 ร้าน (view `public_product`); admin เห็นทั้งหมดและตัดสินรายการ REVIEW / ย้ายกลุ่ม / บันทึกเลิกขาย

อัปโหลดไฟล์ตรงที่ `/admin/import` ยังใช้ได้

## คำถามที่ยังเปิด

- ชุดโปรโมชัน ("กด 2 ฟรี 1") และ Refill pack นับเป็นชนิดเดียวกับสินค้าปกติไหม
- เงื่อนไขของ Shopee Affiliate: อนุญาตให้ใช้เครื่องมืออัตโนมัติกับพอร์ทัล/หน้าค้นหา และนำข้อมูลสินค้าไปแสดงบนเว็บแค่ไหน
- วิธีทำ F2 ที่ไม่ต้องคัดลอกมือ (Ctrl+S ไม่ได้ข้อมูล)
- ขยายไปสินค้าอื่น: คำค้นเดียวต่อรอบ หรือหลายร้าน/หลายหมวด
- admin หลายคน มีรหัสของตัวเองและ role (เช่น `UPLOADER` วางไฟล์/ดูพรีวิวได้อย่างเดียว)
- แสดงรูปสินค้า: ฝังจาก susercontent.com หรือเก็บเอง
